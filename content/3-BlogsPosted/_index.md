###  [Blog 1 - Serverless Pipeline: Import data from S3 to DynamoDB](3.1-Blog1/)
This blog introduces the process of importing data from S3 to DynamoDB, automated using Lambda. This lab helps you understand that S3 acts as the data receiver, Lambda processes the data based on events and DynamoDB is where the processed data is stored. You have a serverless pipeline without needing EC2, Glue or Glue Crawler.
